
# P11 - Newspaper Layout Using CSS Grid

## Objective
To create a newspaper-style webpage using CSS Grid with
three columns and multiple article sections.

## Files
- index.html: Contains the newspaper structure and articles.
- style.css: Contains the design and CSS Grid layout.
- README.md: Explains the project and concepts.

## HTML Concepts
- header: Defines the newspaper heading.
- nav: Contains navigation links.
- main: Contains the main newspaper content.
- article: Represents an individual news story.
- footer: Defines the bottom section.

## CSS Grid Concepts
- display: grid: Activates CSS Grid.
- grid-template-columns: Defines the number and size of columns.
- repeat(3, 1fr): Creates three equal columns.
- gap: Adds space between grid items.
- grid-column: span 2: Makes an item occupy two columns.
- 1fr: Represents one fraction of the available space.

## Responsive Design
Media queries change the layout:
- Desktop: Three columns.
- Tablet: Two columns.
- Mobile: One column.

## How to Run
Open index.html in a web browser.

## Learning Outcome
Learned how to create multi-column newspaper layouts
using CSS Grid and responsive media queries.
