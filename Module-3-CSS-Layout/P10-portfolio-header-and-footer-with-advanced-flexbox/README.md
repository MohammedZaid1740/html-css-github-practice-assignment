
# P10 - Advanced Flexbox Header and Footer

## Objective
To create a responsive webpage using advanced CSS Flexbox properties
for arranging header, navigation, project cards and footer sections.

## Files
- index.html: Contains the webpage structure.
- style.css: Contains styling and Flexbox layouts.
- README.md: Explains the project and concepts used.

## HTML Concepts
- header: Defines the webpage header.
- nav: Contains navigation links.
- main: Contains the main webpage content.
- section: Divides content into sections.
- footer: Defines the bottom section of the webpage.
- div: Groups related elements.

## CSS Flexbox Concepts
- display: flex: Activates Flexbox.
- justify-content: Distributes items horizontally.
- align-items: Aligns items along the cross axis.
- flex-direction: Changes the direction of items.
- flex-wrap: Allows items to move onto another line.
- flex: Controls how flex items grow and shrink.
- gap: Adds space between flex items.
- width: 100%: Makes the footer bottom occupy the full row.

## Responsive Design
Media queries are used to adjust the header, navigation,
hero section and footer for smaller screens.

## How to Run
Open index.html in a web browser.

## Learning Outcome
Learned how to create responsive headers and footers
using advanced CSS Flexbox properties.
