
# P12 - Portfolio Projects Grid Using CSS Grid

## Objective
To create a portfolio webpage that displays project cards
using CSS Grid with different column sizes and responsive layouts.

## Files
- index.html: Contains the portfolio structure and project cards.
- style.css: Contains styling and CSS Grid properties.
- README.md: Explains the project and concepts used.

## HTML Concepts
- header: Creates the top navigation area.
- nav: Contains navigation links.
- main: Contains the main webpage content.
- section: Groups related content.
- article: Represents an individual project card.
- footer: Creates the bottom section.

## CSS Grid Concepts
- display: grid: Activates CSS Grid.
- grid-template-columns: Defines the grid columns.
- repeat(3, minmax(0, 1fr)): Creates three equal responsive columns.
- minmax(): Defines minimum and maximum sizes.
- grid-column: span 2: Makes the featured card occupy two columns.
- gap: Adds spacing between grid items.

## Other CSS Concepts
- border-radius: Rounds the card corners.
- box-shadow: Adds shadows.
- transition: Creates smooth visual changes.
- transform: translateY(): Moves cards vertically.
- media queries: Adjust the layout for different screen sizes.

## Responsive Design
- Desktop: Three-column project grid.
- Tablet: Two-column project grid.
- Mobile: Single-column project grid.

## How to Run
Open index.html in a web browser.

## Learning Outcome
Learned how to create responsive project galleries
using CSS Grid and advanced layout properties.
