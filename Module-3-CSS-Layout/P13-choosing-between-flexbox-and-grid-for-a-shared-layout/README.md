
# P13 - Flexbox vs CSS Grid

## Objective
To understand the differences between CSS Flexbox and CSS Grid
by creating a webpage that demonstrates both layout systems.

## Files
- index.html: Contains the webpage structure.
- style.css: Contains Flexbox, Grid and responsive styling.
- README.md: Explains the project and concepts.

## HTML Concepts
- header: Creates the top section.
- nav: Contains navigation links.
- main: Contains the main content.
- section: Groups related content.
- div: Groups elements for styling.
- footer: Creates the bottom section.

## Flexbox Concepts
- display: flex: Activates Flexbox.
- justify-content: Aligns items along the main axis.
- align-items: Aligns items along the cross axis.
- flex-wrap: Allows items to move onto another line.
- gap: Adds spacing between items.
- flex-direction: Controls row or column direction.

## CSS Grid Concepts
- display: grid: Activates CSS Grid.
- grid-template-columns: Defines columns.
- grid-template-rows: Defines rows.
- grid-template-areas: Gives names to grid areas.
- grid-area: Places an item in a named area.
- gap: Adds spacing between grid items.

## Main Difference
- Flexbox is mainly one-dimensional (row or column).
- CSS Grid is two-dimensional (rows and columns).

## Responsive Design
Media queries adjust the header, Grid layout and comparison
cards for tablet and mobile screen sizes.

## How to Run
Open index.html in a web browser.

## Learning Outcome
Learned when to use Flexbox and CSS Grid and how to
combine both systems to build responsive webpages.
