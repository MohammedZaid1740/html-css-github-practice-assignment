# HTML, CSS and GitHub Practice – 13 Problems

**Created by:** Mohammed Zaid

## About This Repository

This repository contains 13 practical problems completed as part of my HTML, CSS, Git and GitHub learning assignment.

The assignment is divided into three modules. Each module focuses on different concepts, starting with basic terminal and Git commands, followed by HTML and CSS fundamentals, and finally advanced webpage layouts using Flexbox and CSS Grid.

---

# Module 1 – Git and GitHub Basics

**Objective:** To understand terminal navigation, repository creation, Git commands, branching, merging and version tagging.

### P1 – Project Folder and Terminal Navigation
Practised basic terminal commands to navigate directories, create folders and files, and open a project in VS Code.

### P2 – Portfolio Repository
Created a local Git repository for a portfolio project and performed the initial commit using Git commands.

### P3 – Feature Branch Workflow
Practised creating a feature branch, switching between branches, making commits and merging changes into the main branch.

### P4 – README and Version Tags
Created project documentation and learned how to create Git version tags to identify different project versions.

---

# Module 2 – HTML and CSS Fundamentals

**Objective:** To learn semantic HTML, webpage structure, CSS styling, typography, positioning and responsive design.

### P5 – Semantic Bio Page
Created a personal biography webpage using semantic HTML elements such as header, main, section and footer.

### P6 – Portfolio Page Structure
Designed a portfolio webpage containing Home, About, Skills, Projects and Contact sections with navigation links.

### P7 – Design Tokens and Typography
Created a consistent design system using CSS variables for colours, typography, spacing and reusable styling.

### P8 – Sticky Navbar and Card Overlay
Learned CSS positioning by creating a sticky navigation bar and placing overlay badges on cards using relative and absolute positioning.

### P9 – Responsive Navbar and Card Grid
Created a responsive navigation bar and project card layout using Flexbox, flex-wrap and CSS media queries.

---

# Module 3 – Advanced CSS Layout

**Objective:** To understand advanced webpage layouts using CSS Flexbox and CSS Grid.

### P10 – Advanced Flexbox Header and Footer
Created a responsive webpage with an advanced Flexbox header, navigation bar, project cards and footer.

### P11 – Newspaper Layout Using CSS Grid
Designed a newspaper-style webpage with multiple articles using a three-column CSS Grid layout and responsive breakpoints.

### P12 – Portfolio Projects Grid
Created a portfolio project gallery using CSS Grid, responsive columns, featured cards, spacing and hover effects.

### P13 – Flexbox vs CSS Grid
Created a webpage demonstrating both Flexbox and CSS Grid to understand their differences and when to use each layout system.
