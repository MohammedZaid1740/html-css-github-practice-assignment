
# P1: Project Folder and Terminal Navigation

## Problem Statement
Learn how to navigate directories, create folders and files,
and organize a project using the command-line terminal.

## Objective
- Understand basic terminal commands.
- Navigate between directories.
- Create folders and files.
- Understand the project directory structure.
- Open a project folder in Visual Studio Code.

## Commands Used

| Command | Description |
|---------|-------------|
| pwd | Displays the current directory |
| ls | Lists files and folders |
| cd | Changes the current directory |
| cd .. | Moves to the parent directory |
| mkdir | Creates a new directory |
| touch | Creates a new file |
