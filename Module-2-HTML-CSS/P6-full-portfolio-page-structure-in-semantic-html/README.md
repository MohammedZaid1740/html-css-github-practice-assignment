
# P6: Portfolio Page Structure

## Problem Statement
Create a complete personal portfolio webpage using
semantic HTML5 elements and CSS.

## Objective
- Understand semantic HTML page structure.
- Create a navigation bar.
- Organize content into different sections.
- Display skills and projects.
- Create links to different sections.
- Apply CSS styling.

## Files Used

### 1. index.html
Defines the structure and content of the portfolio.

HTML elements used:
- header: Defines the page header.
- nav: Contains navigation links.
- main: Holds the main page content.
- section: Divides the page into sections.
- article: Represents individual projects.
- footer: Defines the page footer.
- a: Creates hyperlinks.
- ul and li: Create lists.

### 2. style.css
Controls the appearance and layout of the portfolio.

CSS properties used:
- display: flex
- justify-content
- align-items
- gap
- padding
- margin
- background-color
- color
- border-radius

### 3. README.md
Documents the project, its files and learning outcomes.

## Portfolio Sections
1. Home
2. About Me
3. Skills
4. Projects
5. Contact

## Technologies Used
- HTML5
- CSS3
- Visual Studio Code

## How to Run
1. Open the project folder in VS Code.
2. Open index.html.
3. Run the file in a web browser.

## Learning Outcome
Learned how to structure a complete portfolio website
using semantic HTML and style its layout using CSS.
