
# P5: Semantic Bio Page

## Problem Statement
Create a personal biography webpage using semantic HTML
elements and CSS styling.

## Objective
- Understand semantic HTML.
- Create a structured biography webpage.
- Use headings, paragraphs and lists.
- Apply CSS styling.
- Connect an external CSS stylesheet.

## Files Used

### 1. index.html
Contains the structure and content of the biography page.

HTML elements used:
- header: Defines the introductory section.
- main: Contains the main webpage content.
- section: Groups related information.
- footer: Defines the bottom section.
- h1 and h2: Define headings.
- p: Displays paragraphs.
- ul and li: Create an unordered list.
- a: Creates a hyperlink.

### 2. style.css
Controls the appearance of the webpage.

CSS properties used:
- margin: Controls outside spacing.
- padding: Controls inside spacing.
- background-color: Sets background colors.
- color: Changes text color.
- font-family: Sets the font.
- text-align: Aligns text.
- border-radius: Rounds the corners.
- max-width: Limits the content width.

### 3. README.md
Documents the problem, files, technologies and learning outcomes.

## Technologies Used
- HTML5
- CSS3
- Visual Studio Code

## How to Run
1. Open the project folder in VS Code.
2. Open index.html.
3. Run it in a web browser.

## Learning Outcome
Learned how to create a structured biography page
using semantic HTML and style it using CSS.
