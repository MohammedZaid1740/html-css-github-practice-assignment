
# P8: Sticky Navbar and Card Overlay

## Problem Statement
Create a webpage with a sticky navigation bar and
project cards containing overlay badges using CSS positioning.

## Objective
- Understand CSS positioning.
- Create a sticky navigation bar.
- Use relative and absolute positioning.
- Understand the z-index property.
- Create overlay elements inside cards.

## Files Used

### 1. index.html
Contains the navigation bar, hero section, project cards,
about section and contact section.

HTML elements used:
- nav: Creates navigation.
- header: Defines introductory content.
- main: Contains the main page content.
- section: Groups related content.
- article: Represents an individual project.
- span: Represents the overlay badge.
- footer: Defines the bottom section.
- a: Creates navigation links.

### 2. style.css
Controls the layout, colors and positioning.

CSS concepts used:

#### position: sticky
Keeps the navigation bar at the top while scrolling.

#### position: relative
Creates a positioning reference for the badge.

#### position: absolute
Positions the badge inside the card image area.

#### z-index
Controls the stacking order of overlapping elements.

#### Other CSS properties
- top
- right
- display
- flex-wrap
- justify-content
- align-items
- border-radius
- box-shadow

## Technologies Used
- HTML5
- CSS3
- Visual Studio Code

## How to Run
1. Open the project folder in VS Code.
2. Open index.html in a web browser.
3. Scroll the webpage to test the sticky navbar.
4. Observe the badges on the project cards.

## Learning Outcome
Learned how to use CSS positioning to create sticky
navigation and overlay elements inside project cards.
