
# P9: Responsive Navbar and Card Grid using Flexbox

## Problem Statement
Create a responsive portfolio webpage using CSS Flexbox
and media queries to adapt the navigation bar and project
cards to different screen sizes.

## Objective
- Understand CSS Flexbox.
- Create a responsive navigation bar.
- Arrange project cards using Flexbox.
- Use flex-wrap to wrap cards.
- Apply media queries for different screen sizes.

## Files Used

### 1. index.html
Contains the navigation bar, hero section, about section,
project cards, contact section and footer.

HTML elements used:
- header
- nav
- main
- section
- article
- div
- ul and li
- a
- footer

### 2. style.css
Controls the responsive layout and appearance.

CSS concepts used:

#### Flexbox
- display: flex
- justify-content
- align-items
- flex-wrap
- flex-direction
- gap
- flex-grow
- flex-shrink
- flex-basis

#### Media Queries
- @media (max-width: 768px)
- @media (max-width: 480px)

#### Other CSS properties
- max-width
- padding
- margin
- border-radius
- box-shadow
- background-color

## Responsive Design
- Desktop: Navigation links appear horizontally and cards
  are arranged in multiple columns.
- Tablet: Navigation changes to a vertical arrangement
  and cards adjust to the available width.
- Mobile: Cards are displayed in a single column.

## Technologies Used
- HTML5
- CSS3
- Flexbox
- Media Queries
- Visual Studio Code

## How to Run
1. Open the project folder in VS Code.
2. Open index.html in a browser.
3. Resize the browser to test desktop, tablet and mobile layouts.

## Learning Outcome
Learned how to create responsive web layouts using
Flexbox and CSS media queries.
