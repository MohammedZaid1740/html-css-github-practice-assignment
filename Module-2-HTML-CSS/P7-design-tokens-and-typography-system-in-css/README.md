
# P7: Design Tokens and Typography System

## Problem Statement
Create a reusable CSS design system using custom properties
for colors, typography and spacing.

## Objective
- Understand CSS variables.
- Create reusable design tokens.
- Define a consistent color palette.
- Establish typography sizes.
- Create reusable spacing values.
- Apply tokens throughout a webpage.

## Files Used

### 1. index.html
Contains the webpage structure and demonstrates
the design system.

HTML elements used:
- header
- main
- section
- h1, h2 and h3
- p
- div
- button
- footer

### 2. style.css
Defines and applies the design tokens.

CSS concepts used:

#### :root
Defines reusable CSS custom properties.

#### Colors
- --color-one
- --color-two
- --color-three
- --background-color
- --text-color

#### Typography
- --font-family
- --font-small
- --font-normal
- --font-large
- --font-heading

#### Spacing
- --space-small
- --space-medium
- --space-large

#### Other properties
- var()
- font-size
- padding
- margin
- border-radius
- background-color

### 3. README.md
Documents the problem and explains the implementation.

## Technologies Used
- HTML5
- CSS3
- CSS Custom Properties
- Visual Studio Code

## How to Run
1. Open the project in VS Code.
2. Open index.html in a browser.
3. View the typography, colors and spacing examples.

## Learning Outcome
Learned how to create reusable design tokens using
CSS variables and maintain consistent typography,
colors and spacing throughout a webpage.
